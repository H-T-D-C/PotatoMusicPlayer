# Potato Music Player - 波形ズーム・スクロール機能 仕様書

## 現行仕様（2026-09-23 集約）

この節は、実装途中に更新された仕様を一箇所に集約したものです。以下と本文の旧記載が矛盾する場合は、この節を優先します。

### 表示と操作

- 波形の表示範囲は、秒数または曲全体に対するパーセンテージで指定できる。入力値 `5` は 5 秒、`5%` は曲全体の 5% として受け付ける。
- 表示範囲の値は波形ボックスの中央上に表示し、クリックで「秒」と「%」の表示を切り替える。
- 「表示 > 波形 > 範囲を指定して拡大」は、現在表示している波形の中心を基準に拡大・縮小する。左流モードでも再生位置を基準にはしない。
- 「再生 > 指定箇所へ移動」は、時刻（`hh:mm:ss.ss`、秒）またはパーセンテージを指定して再生位置を移動する。
- 上記の入力ダイアログは Esc でキャンセルし、正しい値を入力した場合だけ Enter で確定する。
- シークバーとミニマップは波形の直下に置き、再生操作・音量操作はその下に置く。

### 再生ヘッドとミニマップ

- 中央固定モードでは、再生ヘッドは常に中央線として表示する。曲の先頭・末尾では波形の始端・終端を中央線に合わせ、存在しない時間は空白にする。
- 中央固定モードで波形またはミニマップを操作した後は、移動後の表示範囲の中央から再生する。一時停止中は再生を開始しない。
- 左流モードで波形を操作した場合は波形範囲を維持して、操作位置へ再生位置を移動する。
- 左流モードでミニマップを操作した場合、元の再生位置が新しい範囲内なら保持する。範囲より左なら左端、範囲より右なら中央から再生する。
- 左流モードで表示範囲外へシークした場合、および Loop: 全体／1曲で曲末から先頭へ戻った場合は、表示範囲も該当するページへ移動する。

### 設定

- 「表示 > 波形を表示」と「再生ヘッドを中央に固定」の状態は設定画面の波形設定と常に一致させる。中央固定をオフにすると左流モードとなる。
- 波形の横・縦方向詳細度は 0〜100。横は描画密度、縦 0 は音の有無のみを示す。
- 波形表示範囲は、既定値を秒または%で設定でき、復元するかを一般設定で選択できる。
- 波形／ミニマップは折りたたみ可能な詳細カテゴリとし、詳細カテゴリの右端に初期化ボタンを置く。
- ホットキーを含む設定領域のスクロールバーは細く表示する。未適用の値には項目ごとの `*` を表示する（実装継続中）。
- 数値設定の「曲の切替待機時間 (秒)」は曲末から次の再生を開始するまでの待機時間。Loop: 1曲／全体にも適用し、既定値は 0 秒。

## 概要
再生中の曲の詳細な波形を確認するため、波形表示エリアのズーム・スクロール機能を実装する。
長尺メディア(数時間の講演など)の細かい部分を正確に探すユースケースを想定。

## 機能仕様

### 1. ズーム・スクロール操作

#### 1-1. ハンドルドラッグ（下部バー範囲指定）
- **左ハンドル**: ドラッグ → 表示範囲の**開始時刻**を変更（スクロール）
- **右ハンドル**: ドラッグ → 表示範囲の**終了時刻**を変更（ズーム）
- **Shift + 左右ハンドル同時ドラッグ**: 範囲全体を拡大・縮小（ズーム IN/OUT）
  - マウス位置が右に動く → ズーム IN（表示幅狭まる）
  - マウス位置が左に動く → ズーム OUT（表示幅広がる）

#### 1-2. キーボード/スクロール操作
- **Ctrl + マウスホイール（波形エリア内）**: ズーム IN/OUT
  - Up → ズーム IN（表示幅狭まる、最小値に達したら停止）
  - Down → ズーム OUT（表示幅広がる）
- **Shift + マウスホイール（波形エリア内）**: 表示範囲スクロール
  - Up → 右方向スクロール（将来の時刻へ）
  - Down → 左方向スクロール（過去の時刻へ）
- **マウスホイール単体**: 表示範囲スクロール（Shift と同じ）

#### 1-3. ミニマップドラッグ（範囲オーバーレイドラッグ）
- ミニマップ上の**範囲オーバーレイ（カラーハイライト部分）**をドラッグ → 表示範囲全体を移動
- ダイレクトスクロール操作
- 波形エリア上のドラッグ動作はカーソルモードごとに「3-1」の定義に従う。
- 再生中にミニマップ操作を終えた場合、中央固定型は移動後の表示範囲の中央時刻から再生を再開する。左流型は、現在の再生位置が移動後の表示範囲内ならその位置を維持し、範囲より左なら表示範囲の開始時刻、範囲より右なら表示範囲の中央時刻から再生する。
- 一時停止中のミニマップ・波形操作は再生を開始しない。

---

### 2. ズームレベル管理

#### 2-1. ズームレベル定義
- **単位**: 秒（表示範囲の幅）
- **初期値**: メディア全体の長さに応じて自動設定
  - 例: 60分のメディア → 初期表示幅 60秒（全体の1/60を表示）
- **最小値（最大ズーム IN）**: 1秒（設定可能。メディア全体が1秒未満の場合はメディア全体）
- **最大値（最大ズーム OUT）**: メディア全体の長さ（フルビュー）

#### 2-2. ズーム操作の計算
```
新ズームレベル = 現在のズームレベル × ズーム倍率
ズーム倍率: デフォルト 2.0倍（設定可能）
  - ズーム IN: 現在の表示幅 ÷ 2.0
  - ズーム OUT: 現在の表示幅 × 2.0
制約: 最小値 ≤ 新ズームレベル ≤ 最大値
```

#### 2-3. スクロール操作の計算
```
新開始時刻 = 現在の開始時刻 + スクロール量
制約: 
  0 ≤ 新開始時刻
  新開始時刻 + ズームレベル ≤ 全体時間
```

---

### 3. 再生ヘッド（現在位置カーソル）の動作モード

#### 3-1. 設定項目: `CursorMode`

**モード A: 中央固定型（推奨・デフォルト）**
- 再生ヘッドカーソルは常に波形エリアの**中央**に固定表示
- 波形は時間の経過とともに**背景が右方向に流れていく**（NLE/DAW風）
- 表示範囲は再生位置に追従し、フレーム間の移動は再生時間から補間して滑らかに表示する
- 曲の先頭・末尾付近でも再生ヘッドは中央固定とし、存在しない時間帯は空白で表示する。曲の開始・終了位置が中央線へ到達する。
- 波形エリアをドラッグした場合は、表示範囲（背景波形）だけを移動する。ドラッグ終了時には移動後の表示範囲の中央時刻から再生を開始し、再生ヘッドは中央表示を維持する。
- ミニマップをドラッグしている間も、波形エリアの再生ヘッドは常に中央に固定する。
- ユースケース: 詳細な波形を確認しながら再生・編集位置を追跡

**モード B: 左流型**
- 再生ヘッドカーソルは左から右に**流れていく**
- 波形は停止したままで、カーソルが右端に到達したら**次の範囲に瞬間ジャンプ**
- 波形エリアをドラッグした場合は、表示範囲を維持したままドラッグ位置へ再生位置を移動する
- ミニマップ操作後、元の再生位置が表示範囲内ならその位置を維持する。範囲より左なら左端、範囲より右なら中央を再生開始位置とする。
- ユースケース: スクロールなしで連続再生確認

#### 3-2. 両モード共通
- 下部バーのシークスライダーは常に**絶対位置**を表示（どのズームレベルでも一定）
- 下部バーのヘッドカーソルはズーム状態に関わらず、表示範囲内なら表示

---

### 4. ミニマップ表示

#### 4-1. レイアウト
- 位置: 下部バーの時間表示エリア直下
- サイズ: 時間表示エリアと同じ幅、高さ 16px（固定または設定可）
- 背景: メディア全体の波形をグレースケール表示

#### 4-2. 範囲オーバーレイ
- 色: 明るい色でハイライト（例: アクセントグリーン `#64C864` など）
- 形状: 四角形(矩形)
- 左右のハンドル: 幅 8px、高さ 16px（ミニマップと同じ）
- マウスオーバー時: カーソルを `col-resize` に変更

#### 4-3. ミニマップ上でのマウス操作
- **ハンドルドラッグ**: 上記「1-1」参照
- **範囲オーバーレイドラッグ**: 表示範囲全体を移動
  - **ハンドル以外の場所クリック**: 該当時刻へ再生位置を移動し、その位置を中心に表示範囲も移動

### 5. 設定項目（Settings.xaml追加予定）

```csharp
// AppSettings.cs に追加
public class WaveformZoomSettings
{
    // ズーム設定
    public float MinZoomLevel { get; set; } = 1.0f;  // 秒
    public float ZoomFactor { get; set; } = 2.0f;    // 倍率
    
    // スクロール設定
    public float ScrollStepSize { get; set; } = 0.2f;  // 秒

    // カーソル動作モード
    public CursorDisplayMode CursorMode { get; set; } = CursorDisplayMode.CenterFixed;
    
    // ミニマップ
    public bool ShowMinimap { get; set; } = true;
    public int MinimapHeight { get; set; } = 16;  // px
}

public enum CursorDisplayMode
{
    CenterFixed = 0,  // 波形が流れるモード
    LeftScroll = 1    // カーソルが流れるモード
}
```

### 5-1. 波形ズームのホットキー

- 設定画面の「ホットキー」で、波形の拡大・縮小を個別に設定できる。
- 初期値は「Ctrl + マウスホイール上」で拡大、「Ctrl + マウスホイール下」で縮小とする。
- キーボード入力（例: `Shift + O`）と、修飾キー付きマウスホイール入力の両方を受け付ける。マウスホイール入力は波形エリア上で実行する。

### 5-2. 波形の詳細度

- 横方向詳細度・縦方向詳細度をそれぞれ `0`〜`100` で設定できる。
- 横方向詳細度が低いほど、表示する波形バーの本数を減らして粗く表示する。
- 縦方向詳細度が `0` の場合は、音の有無だけを `0`／`1` で表示する。
- 表示設定では「波形」「ミニマップ」の詳細カテゴリを折りたたみ可能とし、それぞれの設定を初期化できる。

### データモデル: WaveformZoomState.cs

```csharp
public class WaveformZoomState
{
    // ズームレベル（表示幅・秒）
    public double CurrentZoomLevel { get; set; }
    
    // 表示範囲
    public double VisibleRangeStart { get; set; }  // 開始時刻（秒）
    public double VisibleRangeEnd { get; set; }    // 終了時刻（秒）
    
    // メディア全体
    public double TotalDuration { get; set; }      // 全体時間（秒）
    
    // ズーム制約
    public double MinZoomLevel { get; set; }       // 最小ズームレベル（秒）
    public double MaxZoomLevel { get; set; }       // 最大ズームレベル（秒）
    
    // カーソル表示位置（現在時刻）
    public double CurrentPlaybackPosition { get; set; }
    
    // 派生プロパティ
    public double VisibleRangeDuration => VisibleRangeEnd - VisibleRangeStart;
    public double ZoomRatio => TotalDuration / CurrentZoomLevel;  // 拡大率
}
```

}

// スクロール（波形エリア内）
private void WaveformCanvas_MouseWheel(object sender, MouseWheelEventArgs e)
{
    if ((Keyboard.Modifiers & ModifierKeys.Control) == ModifierKeys.Control)
    {
        // Ctrl + Scroll: ズーム
        if (e.Delta > 0)
            _viewModel.ZoomIn();
        else
            _viewModel.ZoomOut();
    }
    else if ((Keyboard.Modifiers & ModifierKeys.Shift) == ModifierKeys.Shift ||
             (Keyboard.Modifiers & ModifierKeys.None) == ModifierKeys.None)
    {
        // Shift + Scroll または単純Scroll: スクロール
        if (e.Delta > 0)
            _viewModel.ScrollRight();
        else
            _viewModel.ScrollLeft();
    }

    e.Handled = true;
}

// 波形描画更新（ZoomState が変わったら毎回呼ぶ）
private void UpdateWaveformDisplay()
{
    if (_viewModel.CurrentWaveformData == null)
        return;

    float[] fullData = _viewModel.CurrentWaveformData;
    var zoomState = _viewModel.ZoomState;

    // フルデータから表示範囲のみを抽出・描画
    int startIndex = (int)(zoomState.VisibleRangeStart / zoomState.TotalDuration * fullData.Length);
    int endIndex = (int)(zoomState.VisibleRangeEnd / zoomState.TotalDuration * fullData.Length);

    float[] visibleData = new float[Math.Max(1, endIndex - startIndex)];
    Array.Copy(fullData, startIndex, visibleData, 0, visibleData.Length);

    DrawWaveform(visibleData);
    DrawPlaybackCursor(zoomState);
}

## パフォーマンス・技術ノート

1. **波形データキャッシュ**: フルデータを常にメモリ保持（数時間でも数MB程度）
2. **描画最適化**: Canvas への描画は `WaveformCanvas.Children.Clear()` → 新描画（既存実装継続）
3. **ズーム中のカーソル更新**: 
   - CenterFixed モード: 表示範囲を自動調整（カーソルを中央に保つ）
   - LeftScroll モード: カーソルが右端到達時に範囲をシフト
4. **ハンドルドラッグの感度**: ピクセル単位で計算、最小ズームレベルで停止
5. **メモリ効率**: 波形データは `float[]` で保持（圧縮不可、フルビュー専用）

### 中央固定モード

| ID | 再現条件 | 現在の問題 | 期待動作 |
| --- | --- | --- | --- |
| CF-01 | 一時停止中に既存の再生バーを操作する | 操作後に再生が開始される | 再生位置だけを変更し、一時停止状態を維持する |
| CF-02 | 一時停止中に波形上を操作して再生位置を変更する | 操作後に再生が開始される | 再生位置だけを変更し、一時停止状態を維持する |
| CF-03 | 一時停止中に波形上で大きく離れた位置へシークする | 再生位置が先頭へ戻り、再生が開始される | 指定位置で一時停止状態を維持する |
| CF-04 | 拡大中で、再生位置が曲の先頭付近または末尾付近にある | 波形上の再生位置カーソルがぶれる | カーソルと波形表示を安定して描画する |
| CF-05 | 拡大中で、再生位置が曲の先頭・末尾以外にある | 背景の波形がぶれる | 再生位置の追従中も背景波形を滑らかに移動する |
| CF-06 | 等倍表示中に再生しながら波形をドラッグする | 再生位置は変わるが一時停止されず、音声が途切れ途切れになる | カーソルモード別のドラッグ仕様へ置き換えるため、現時点では修正対象外 |
| CF-07 | 中央固定モードで波形またはミニマップの表示範囲をドラッグする | ドラッグ中に自動追従と競合して表示範囲が戻る | ドラッグ中だけ手動範囲を維持し、終了後は通常の再生追従へ復帰する |
| CF-08 | 再生中に波形をドラッグする | ミニマップの範囲は動くが、再生位置の更新と追従状態が不整合になる | ドラッグ終了時に表示範囲中央へシークし、再生位置・波形・ミニマップの追従状態を同期する |

### 左流しモード

| ID | 再現条件 | 現在の問題 | 期待動作 |
| --- | --- | --- | --- |
| LS-01 | 拡大中に再生する | 波形上の再生位置カーソルがぶれる | カーソルを安定して左から右へ移動させる |
| LS-02 | 拡大中に下部ミニマップの範囲オーバーレイまたはハンドルを移動する | 再生位置が意図せずずれる | 表示範囲だけを変更し、再生位置は維持する |
| LS-03 | 再生中に波形をドラッグして離す | 再生状態表示と実際の再生位置更新が競合し、再生バーが停止・不安定になった後に操作不能になることがある | ドラッグ中は表示のみを更新し、離した位置へ一度だけ安全にシークする |
| LS-04 | 再生中に波形またはミニマップをドラッグした後、再生位置カーソルが右端へ到達する | 手動操作時の追従抑制が残り、次の表示範囲へ切り替わらない | ドラッグ終了後に左流しの自動ページ切替を再開する |

### 操作・波形データ共通

| ID | 再現条件 | 現在の問題 | 期待動作 |
| --- | --- | --- | --- |
| OP-01 | Shift を押しながらミニマップの右ハンドルをドラッグする | 左ハンドルと同じ方向で倍率を計算するため、右ハンドルのドラッグ方向に対する拡大・縮小が逆になる | 左ハンドルは従来の方向を維持し、右ハンドルはその逆方向で倍率を変更する |
| WD-01 | 曲の終端付近を表示する | 実際には音が鳴っていない終端部分にも波形が表示される | 音声データの時間位置と波形データの位置を一致させ、無音の終端を正しく表示する |

### ドラッグ中の波形プレビュー案

- ミニマップのハンドルをドラッグしている間は、開始時点の波形を `ScaleTransform` と `TranslateTransform` で暫定表示する。
- マウスを離した時点で確定した表示範囲から波形を再集約して描画し、暫定変形を解除する。
- これにより、ドラッグ中に多数のバーを作り直すことを避け、表示の滑らかさと操作応答を両立させる。
- 暫定表示はプレビューであり、確定後の波形は必ず元データから再生成する。

### 修正方針

- まず一時停止中のシークが再生を開始しないこと（CF-01〜03）を独立して修正する。
- 次に、Shift 操作の左右ハンドルの方向対応（OP-01）と、波形データ末尾の割り当て（WD-01）を修正する。
- 次に、再生位置・表示範囲・描画用補間値の更新責務を整理し、中央固定と左流しで共通する描画のぶれを修正する。
- 各修正後に、両モード、拡大・等倍、先頭・中央・末尾、一時停止・再生中を組み合わせて確認する。
