# 波形・ズーム・ミニマップ仕様書

## 1. 目的と用語

曲全体の音量波形から、任意の時間範囲を拡大して確認する。以下では、曲全体の時間を `T`、現在表示している範囲を `[S, E]`、表示幅を `W = E - S` と表す。

- **波形**: 現在の表示範囲を描画する大きな波形。
- **ミニマップ**: 曲全体の波形と、現在範囲のオーバーレイを表示する小さな波形。
- **表示範囲**: 波形に表示する時間区間。
- **中央固定モード**: 再生位置を波形中央の線に固定するモード。
- **左流モード**: 波形を固定し、再生位置の線が左から右へ進むモード。

## 2. 画面配置

上から次の順に配置する。

1. 波形ボックス
2. 波形ボックス上部中央の表示範囲ラベル
3. シークバー
4. ミニマップ
5. 再生／停止、速度、ループ、音量などのトランスポート操作

表示範囲ラベルはクリックで秒表示とパーセンテージ表示を切り替える。

## 3. ズームの仕様

### 3.1 範囲と倍率

- 表示幅は秒で管理する。
- ズームは秒数の加減算ではなく倍率で行う。
- ズームインは `W / ZoomFactor`、ズームアウトは `W * ZoomFactor`。
- 最小表示幅は既定値1秒で、設定で変更できる。
- 最小表示幅が曲全体より長い場合は曲全体を表示する。
- 最大表示幅は曲全体 `T`。

### 3.2 ズーム操作

- 波形上の `Ctrl + マウスホイール上／下`: ズームイン／アウト
- 波形上の通常ホイールまたは `Shift + マウスホイール`: 表示範囲を左右へ移動
- ミニマップ左ハンドル: 表示範囲の開始側を変更
- ミニマップ右ハンドル: 表示範囲の終了側を変更
- `Shift` を押したハンドル操作: 表示範囲の中央を固定して両端を同時に変更
- ミニマップの範囲内部: 表示範囲全体を移動

ハンドルは左右で意味を反転させず、つまんだ側の端を固定し、反対側との距離を制約内で変更する。

## 4. 再生ヘッドモード

### 4.1 中央固定モード

- 再生位置は波形の中央線で表示する。
- 再生中は波形の表示範囲が再生位置に追従する。
- 曲の先頭では曲の始端を中央線へ合わせ、曲の末尾では曲の終端を中央線へ合わせる。曲外の領域は空白にする。
- 波形をドラッグすると、再生位置を動かさず表示範囲だけを移動する。ドラッグ終了後は移動後の範囲中央から再生する。
- ミニマップをドラッグしている間も中央線は中央に固定する。
- 一時停止中のドラッグ終了時は、範囲だけを確定し、再生は開始しない。

### 4.2 左流モード

- 波形は基本的に固定し、再生位置の線が左から右へ進む。
- 線が表示範囲の右端へ到達したら、次の表示ページへ移動する。
- 波形をドラッグすると、表示範囲を維持したままドラッグ位置へ再生位置を移動する。
- ミニマップ移動後、元の再生位置が新範囲内ならその位置を維持する。
- 元の位置が新範囲より左なら新範囲の左端から、右なら新範囲の中央から再生する。
- Loop: 全体／1曲で先頭へ戻った場合は、表示範囲も先頭ページへ戻す。
- 一時停止中のドラッグ終了時は再生を開始しない。

### 4.3 共通シーク動作

- 下部シークバーは曲全体に対する絶対位置を示す。
- 波形またはミニマップからクリック位置へシークできる。
- 再生中に操作を開始した場合、必要に応じて一時停止し、操作終了時の位置から再生を再開する。

## 5. 入力と表示範囲指定

### 5.1 表示範囲の指定

「表示 > 波形 > 範囲を指定して拡大」で入力する。

- `5`: 5秒
- `5%`: 曲全体の5%
- `100%`: 曲全体

現在表示している範囲の中央を基準に、新しい表示幅を設定する。左流モードでも再生位置を基準にしない。

### 5.2 指定箇所への移動

「再生 > 指定箇所へ移動」で入力する。

- `3.2`: 3.2秒
- `3:20`: 3分20秒
- `1:01:10`: 1時間1分10秒
- `25%`: 曲全体の25%

入力ダイアログは Esc でキャンセルできる。Enter は値が正しいときだけ確定する。

## 6. 波形生成と詳細度

- 波形データは非同期で生成し、生成中は進捗を表示する。
- 曲全体のピーク値を保持し、表示範囲に対応する部分を描画する。
- 横方向詳細度は0〜100で、低いほど描画バー数を減らす。
- 縦方向詳細度は0〜100で、0の場合は音の有無を0／1で表示する。
- ミニマップの高さは設定可能とする。

## 7. 設定項目

| 項目 | 既定値 | 説明 |
| --- | ---: | --- |
| カーソルモード | 中央固定 | オフ時は左流モード |
| 最小表示幅 | 1秒 | 最大ズームイン時の幅 |
| ズーム倍率 | 2倍 | ホイール・ハンドル操作の倍率 |
| スクロール幅 | 0.2秒 | ホイール移動量 |
| 横方向詳細度 | 100 | 波形バーの密度 |
| 縦方向詳細度 | 100 | 振幅の段階数 |
| 波形の拡大率を復元 | オフ | 次回読み込み時に表示幅を復元 |
| 既定波形表示範囲 | 100% | %または秒で指定 |
| ミニマップ高さ | 16px | ミニマップの高さ |

設定変更後、適用前の項目には入力欄左上へ `*` を表示する。適用またはキャンセルで状態を更新する。

## 8. 既知の制限

- 波形操作の細かな再生同期は、再生状態・ズーム倍率・曲末付近の組み合わせによって手動確認が必要。
- 波形生成が完了する前は、該当範囲の波形が未表示になる場合がある。
- アプリ起動時、設定画面、Windows 標準ファイル選択ダイアログの一瞬の白表示は WPF／Windows の初期描画問題として対象外。
- プレイリスト未実装のため、Loop: 全体は同一曲の先頭へ戻る。

## 10. メモ
### 意図しない挙動
- 英訳未対応箇所
	- 指定箇所へ移動・範囲を指定して拡大の入力ダイアログ
	- 表示設定の詳細カテゴリのタイトル
	- メインウィンドウの表示範囲
	- Loopモードの表示
- ライトモード未対応箇所
	- ホットキー設定(に限らず)のスクロールバー(もっと白っぽく)
	- ミニマップの背景(黒背景白波ではなく、ライトグレイを背景に、ダークグレイの波を)
	- ミニマップの拡大箇所の緑色のオーバーレイ(薄い緑にする)
	- 設定の適用ボタンや、指定箇所へ移動、範囲を指定して拡大の「適用(OK)」ボタンの緑色が濃すぎるので、ライトモードでは薄い緑にする
- 表示が崩れている場所
	- 詳細カテゴリの初期かボタン(右半分が表示されない)
	- 数値設定の入力ボックスのサイズがおかしい(一番上だけちょっと大きい)。また、数値が上寄りになっているので、ボックスの中央に表示されるようにする。
	- 数値設定のうち、単位を指定できる項目の、数値入力ボックスのサイズが他の物と合わない。
	- ウィンドウサイズをできるだけ小さくしたとき、再生ボタンや音量バーのつまみが、ウィンドウの下端に隠れてしまう。
- 意図しない動作
	- 左流モードで拡大しているときに設定を開き、適用後にメインウィンドウに戻ると、波形の表示範囲はそのままで、ミニマップの表示範囲が100%に戻ってしまう。
	- 左流モードで拡大しているときにミニマップを使って表示範囲を変更すると、ドラッグを解除した後にミニマップと波形の位置が少しズレることがある。(このとき、再生位置が左端から始まっていないので、これも関係しているかもしれない)

### 仕様変更案
- 倍速関連
	- 倍速も音量のようにバーで調節できるようにする？それとも、YouTubeのように、1.0倍、1.25倍、1.5倍、2.0倍などのプリセットを用意する？(プリセットはホットキーで切り替えられるようにしても良いし、ボタンをいくつか用意するのもあり)
	- 倍速したとき、ピッチを変更するのか、維持するのかを設定できるように。
	- ファイル長に合わせて倍速する機能。(例：ファイル長が3:20の音声を、ぴったりファイル長が3分になるように倍速したいとき、手動で計算して倍速率を設定するのは大変。)
- mp3等だけではなく、mp4やwebmなどの動画ファイルも再生できるようにする。この時、音声のみ再生する。
- その他　にヘルプを追加。GitHubのWikiにリンクするなどして、操作方法や仕様を確認できるようにする。(じゃあまずWikiを用意しなきゃいけないね)
- ユーザーフレンドリーにしたい場所
	- より多くの言語に対応する。中国語やフランス語、ドイツ語とかの王道系は対応しておいてもいいかもしれない。
	- 設定の適用ボタンを押したときのフィードバックを何かしら追加する(ボタンの色を変える、チェックマークを表示するなど)
	- カスタムフォントを使えるようにする。(webページなどのように、いくつかのフォントを優先度を指定して設定できるようにする。表示が崩れる可能性がある。)
	- 曲にタイトル情報があるときはそれが表示されるが、その時ファイルの拡張子が表示されない。曲のタイトル情報が無い場合はファイル名のみ表記、曲のタイトルがある場合はそれを、拡張子はどちらの場合でも同じ場所に表示する(ビットレートなんかが記載されているところがいいかもね)。
	- 最初へ戻る、最後まで進む、停止等のボタンが白い四角形で囲まれているが、ダサい。アイコンに置き換えるか、現状テキストで実装しているなら別のフォントにするなどして、もう少し見栄えを良くする。
	- 再生バーとミニマップの位置を入れ替える。また、波形を非表示にしたとき、ミニマップ(表示範囲の表記)も非表示にする。
	- タイトルバーの 表示 > 次へ　ボタンが無い。確かに現状プレイリストがないので、次の曲へ移動するボタンは不要だが、将来的にプレイリスト機能を実装する場合は必要になるかもしれない。
	- 数値項目など、各設定項目にホバーしたときに説明文を表示する
	- 再生/停止等四つのボタンを中央に配置、ループモードや倍速は右側に配置する。
	- 数値設定の入力欄に、マウスホイールで値を増減できるようにする。
	- ウィンドウを拡大する機能(タイトルバーをダブルクリック)はあるのに、最大化ボタンがないのは不自然
	- 再生バーや音量調節バーのつまみはもう少し小さくてもいいかもしれない。特に音量バーは、音量を上げるときにマウスカーソルがつまみの上に乗ってしまい、操作しづらい。
	- 再生しているメディアのファイル容量をタイトルの右側(ウィンドウに対して右揃え)に表示する。
	- 波形の読み込みに異常に時間がかかる場合、プログレスを表示する。(ただ現状、そんな激重ファイルを再生したことがないので、必要かどうか分からない。)
- 中央固定モードで、拡大率が1倍(あるいは片側がミニマップ端に近い時)波形をドラッグしても、再生位置が中央に固定されてしまうため、ファイルの最初や最後の部分に再生位置を合わせられない。波形は画面外まで移動できるが、ミニマップは端までしか移動できないため、ミニマップの表示範囲が端に到達した場合の挙動が悩ましい。
- プレイリスト機能を実装したとき、どこに曲一覧を表示するのか。現状、かなり狭いので、曲一覧を表示する場合は、波形やミニマップの高さを縮小する必要があるかもしれない。実際に実装する場合は、UIのレイアウトをどうするかを考える必要がある。
- オーディオビジュアライザー。これもプレイリスト機能と同じく、どこに表示するのかを考える必要がある。波形やミニマップの高さを縮小する必要があるかもしれない。
- スペクトラムアナライザーなど、高度な音声解析機能を実装するかどうか。(ここまでくるとSonic Visualizerみたいな代替手段がある。)
- プラグイン(拡張機能)を実装するかどうか。実装を迷っている、倍速関連の詳細な設定や、オーディオビジュアライザーの種類などを、プラグインとして実装するかどうか。プラグインを実装する場合は、プラグインの仕様をどうするかを考える必要がある。
- ライトモード/ダークモードの仕様の大幅改修。手動によるチェックが必要な箇所が多く、今後のメンテナンス性を考えると、WPFのテーマ切替機能を使って、色やスタイルを一括で切り替えられるようにする方が良いかもしれない。
