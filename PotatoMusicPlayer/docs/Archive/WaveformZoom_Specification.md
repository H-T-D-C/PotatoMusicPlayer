# 波形・ズーム・ミニマップ仕様書

この文書は実装時の個別仕様として保存する。現行仕様は [PotatoMusicPlayer_Specification.md](../PotatoMusicPlayer_Specification.md) を参照する。

## 1. 目的と用語

曲全体の音量波形から、任意の時間範囲を拡大して確認する。以下では、曲全体の時間を `T`、現在表示している範囲を `[S, E]`、表示幅を `W = E - S` と表す。

- **波形**: 現在の表示範囲を描画する大きな波形。
- **ミニマップ**: 曲全体の波形と、現在範囲のオーバーレイを表示する小さな波形。
- **表示範囲**: 波形に表示する時間区間。
- **中央固定モード**: 再生位置を追従時に波形中央へ合わせるモード。中央から外れている間も実際の再生位置を別の線で表示する。
- **左流モード**: 波形を固定し、再生位置の線が左から右へ進むモード。

## 2. 画面配置

上から次の順に配置する。

1. 波形ボックス
2. 波形ボックス上部中央の表示範囲ラベル
3. シークバー
4. ミニマップ
5. 再生／停止、速度、ループ、音量などのトランスポート操作

表示範囲ラベルはクリックで秒表示とパーセンテージ表示を切り替える。

## 3. ズームの仕様

### 3.1 範囲と倍率

- 表示幅は秒で管理する。
- ズームは秒数の加減算ではなく倍率で行う。
- ズームインは `W / ZoomFactor`、ズームアウトは `W * ZoomFactor`。
- 最小表示幅は既定値1秒で、設定で変更できる。
- 最小表示幅が曲全体より長い場合は曲全体を表示する。
- 最大表示幅は曲全体 `T`。

### 3.2 ズーム操作

- 波形上の `Ctrl + マウスホイール上／下`: ズームイン／アウト
- 波形上の通常ホイールまたは `Shift + マウスホイール`: 表示範囲を左右へ移動
- ミニマップ左ハンドル: 表示範囲の開始側を変更
- ミニマップ右ハンドル: 表示範囲の終了側を変更
- `Shift` を押したハンドル操作: 両端を同時に変更。左流モードでは範囲中央を基準にし、中央固定では `Shift` なしでも再生位置の相対割合を基準にした両側ズームになる
- ミニマップの範囲内部: 再生位置が相対的に中央へ向かう向きは範囲のみ動かし、位置は動かさない。中央維持・遠ざかる向きは表示範囲と再生位置を剛体として一緒に移動する（相対割合を維持）。中央固定では曲端が範囲中央に来るまで曲外へ移動でき、左流しでは曲内に制限する。端で範囲が詰まった余剰分も位置へ付け替える。解放時に中央へ寄せることはしない
- ミニマップの範囲枠外: 押した地点を中心に緑枠を移し、押したまま動かす間はマウス位置へ追従する。再生位置はマウスを離した地点で一度だけ確定する
- シーク（再生中）はエンジン適用まで追従を抑止し、古い位置へ表示範囲を引き戻さない
- ミニマップ上には再生位置マーカーを常に表示し、再生中は描画フレームごとの補間位置で滑らかに動かす
- 中央固定での拡大縮小は、再生位置の相対割合を保って行い、再生位置は変更しない（端では丸められる）。左流しでは範囲中央を軸にする
- 波形に曲外の空白があるとき、ミニマップの範囲枠は実際に見えている曲内の部分だけを囲む。例: 波形表示が `[-10,10]` 秒なら、ミニマップの枠は `[0,10]` 秒を示す。曲外へ続く側のハンドルを薄くし、端に外向きの矢印を表示する

左流モードの片側ハンドルは、つまんだ側を動かして反対側を固定する。中央固定モードでは左右のどちらをつまんでも両側ズームになり、位置の相対割合を維持する。

## 4. 再生ヘッドモード

### 4.1 中央固定モード

- 波形中央には薄い目印の線を表示し、実際の再生位置は別の線で表示する。位置が中央に来たときは重なって見える。
- 再生中、再生位置が表示範囲の中央より左にある間は範囲を保持し、中央に追いついた後は範囲が位置に追従する。再生開始時に位置が中央より右にあれば、直ちに範囲を中央合わせする。
- 曲の先頭では曲の始端を中央線へ合わせ、曲の末尾では曲の終端を中央線へ合わせる。曲外の領域は空白にする。
- 波形をドラッグすると、再生位置を動かさず表示範囲だけを移動する。曲の開始・終了地点が中央に来たところで止まり、それ以上は動かない。はみ出した部分は空白になる。ドラッグ終了後は移動後の範囲中央(曲の範囲内に丸める)から再生する。再生中のドラッグでは追従描画がドラッグを上書きしない。
- ミニマップをドラッグしている間も中央線は中央に固定する。
- 一時停止中のドラッグ終了時は、範囲だけを確定し、再生は開始しない。

### 4.2 左流モード

- 波形は基本的に固定し、再生位置の線が左から右へ進む。
- 線が表示範囲の右端へ到達したら、次の表示ページへ移動する。
- 波形をドラッグすると、表示範囲を維持したままドラッグ位置へ再生位置を移動する。
- ミニマップ移動後、元の再生位置が新範囲内ならその位置を維持する。
- 元の位置が新範囲より左なら新範囲の左端から、右なら新範囲の中央から再生する。
- Loop: 全体／1曲で先頭へ戻った場合は、表示範囲も先頭ページへ戻す。
- 一時停止中のドラッグ終了時は再生を開始しない。

### 4.3 共通シーク動作

- 下部シークバーは曲全体に対する絶対位置を示す。
- 波形またはミニマップからクリック位置へシークできる。
- 再生中に操作を開始した場合、必要に応じて一時停止し、操作終了時の位置から再生を再開する。
- シーク（再生の有無を問わず）はエンジン適用まで追従を抑止し、古い位置へ表示範囲を引き戻さない。
- 中央固定では、再生開始時とシークバー操作時に表示範囲を再生位置へ中央合わせする。ただし再生位置が範囲内の中央より左にある間は範囲を動かさず、位置が中央へ追いつくのを待つ。ミニマップ操作の解放時は中央へ寄せない。表示範囲と波形の描画は同じ区間を使う。

## 5. 入力と表示範囲指定

### 5.1 表示範囲の指定

「表示 > 波形 > 範囲を指定して拡大」で入力する。

- `5`: 5秒
- `5%`: 曲全体の5%
- `100%`: 曲全体

中央固定モードでは再生位置の表示範囲内での相対割合を保って、新しい表示幅を設定する。例えば範囲 `[20,40]` 秒で再生位置が25秒なら、10秒幅への変更後は `[22.5,32.5]` 秒になる。左流モードでは現在表示している範囲の中央を基準にする。

### 5.2 指定箇所への移動

「再生 > 指定箇所へ移動」で入力する。

- `3.2`: 3.2秒
- `3:20`: 3分20秒
- `1:01:10`: 1時間1分10秒
- `25%`: 曲全体の25%

入力ダイアログは Esc でキャンセルできる。Enter は値が正しいときだけ確定する。

## 6. 波形生成と詳細度

- 波形データは非同期で生成し、生成中は進捗を表示する。逐次表示が有効な場合は生成途中も先頭から順に描画する。
- 曲全体のピーク値を保持し、表示範囲に対応する部分を描画する。
- 生成結果はキャッシュに保存できる。ファイルサイズと更新時刻で検証し、不一致なら再生成する。
- 横方向詳細度は0〜100で、低いほど描画バー数を減らす。
- 縦方向詳細度は0〜100で、0の場合は音の有無を0／1で表示する。
- ミニマップの高さは設定可能とする。

## 7. 設定項目

| 項目 | 既定値 | 説明 |
| --- | ---: | --- |
| カーソルモード | 中央固定 | オフ時は左流モード |
| 最小表示幅 | 1秒 | 最大ズームイン時の幅 |
| ズーム倍率 | 2倍 | ホイール・ハンドル操作の倍率 |
| スクロール幅 | 0.2秒 | ホイール移動量 |
| 横方向詳細度 | 100 | 波形バーの密度 |
| 縦方向詳細度 | 100 | 振幅の段階数 |
| 波形の拡大率を復元 | オフ | 次回読み込み時に表示幅を復元 |
| 既定波形表示範囲 | 100% | %または秒で指定 |
| 波形の逐次表示 | オン | 生成途中も先頭から順に表示する |
| 波形をキャッシュに保存 | オン | 生成結果をディスクに保存し再利用する |
| 波形のキャッシュ上限 | 512MB | KB/MB/GBで指定、上限超過分は古いものから削除 |
| ミニマップ高さ | 16px | ミニマップの高さ |

設定変更後、適用前の項目には入力欄左上へ `*` を表示する。適用またはキャンセルで状態を更新する。

## 8. 既知の制限

- 波形操作の細かな再生同期は、再生状態・ズーム倍率・曲末付近の組み合わせによって手動確認が必要。
- 波形生成が完了する前は、該当範囲の波形が未表示になる場合がある。
- アプリ起動時、設定画面、Windows 標準ファイル選択ダイアログの一瞬の白表示は WPF／Windows の初期描画問題として対象外。
- プレイリスト未実装のため、Loop: 全体は同一曲の先頭へ戻る。
