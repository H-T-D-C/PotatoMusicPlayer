# 再生・ファイル仕様

本書はファイル読み込みから再生制御までの現行動作を記録する。実装との不一致を見つけた場合はコードを確認し、本書と親仕様書を更新する。

## ファイルを開く

- 対応拡張子は MP3、FLAC、WAV、OGG。
- ファイル選択後、形式を検証して `MediaService.LoadFileAsync` で LibVLC に読み込む。メディア解析はバックグラウンドで実行する。
- 曲名などのメタデータは TagLibSharp から別途取得し、最近使ったファイルへ追加する。再生用の LibVLC 解析とメタデータ取得は独立している。
- 起動引数に対応形式のファイルパスがあれば、そのファイルを起動後に読み込んで再生する。
- 起動時に現在のユーザーの `Software\Classes` へ「プログラムから開く」の登録を追加し、エクスプローラーからアプリで開けるようにする。既定アプリの選択は変更しない。

## 再生状態

- 音量と再生速度はメディア未読込時も希望値を保持し、プレイヤー生成時に適用する。
- 再生中は LibVLC のイベントを受け取り、再生状態・再生位置・曲長を ViewModel へ通知する。UI の状態更新は UI スレッドへ戻す。
- 停止は LibVLC を停止し、再生位置を先頭へ戻す。
- 曲末後に再生を押した場合は先頭へ戻って再生する。終了後に位置を指定した場合は、LibVLC が Ended 状態のまま位置を無視することがあるため、再生開始イベント後に保留位置を再適用する。
- 一時停止状態から位置指定して再開する場合も、再生開始後に位置を再適用する経路がある。

## シークとループ

- 再生位置はサービス内部ではミリ秒、ViewModel と波形 UI では秒で扱う。
- 停止中・終了後のシークは位置を保留し、再生可能になった後で適用する。波形操作中のプレビュー・追従抑止の仕様は [波形詳細仕様](WaveformZoom_Specification.md) を参照する。
- Loop: OFF は曲末で停止状態となる。Loop: 1曲は同じ曲を先頭から再生する。Loop: 全体もプレイリスト未実装のため、現状は同じ曲を先頭から再生する。
- 曲末の再開待ち時間は設定値を 0〜60 秒に制限して適用する。
