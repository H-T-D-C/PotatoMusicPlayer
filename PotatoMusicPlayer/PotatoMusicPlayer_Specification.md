# Potato Music Player 設計・仕様書

## 1. 文書の目的

本書は、Potato Music Player の現行仕様と設計上の責務を定義する。過去の検討案や未実装の構想は記載せず、実装済みの挙動と今後の作業を分けて管理する。

波形表示、ズーム、ミニマップ、再生ヘッドの現行動作も本書に含める。実装時の調査・計画メモは `Unnecessary Documents/` に保存する。

## 2. アプリケーション概要

| 項目 | 内容 |
| --- | --- |
| 対応 OS | Windows 10/11（64bit） |
| UI | .NET 8 WPF |
| 再生エンジン | LibVLCSharp |

| 設定形式 | JSON |
| 初期ウィンドウ | 900 × 400 px |

## 3. 現在実装されている機能

### 3.1 ファイルと再生

- MP3、FLAC、WAV、OGG の読み込み
- 再生、一時停止、停止、先頭へ移動、シーク
- 再生速度の変更（0.25〜2倍）
- 音量変更、最大200%までの音量ブースト、ミュート
- Loop: OFF／1曲／全体
- 曲名、アーティスト、ビットレート、サンプリングレート、再生時間の表示

Loop: 全体は、プレイリスト未実装のため現在の曲を先頭から再生する。

### 3.2 操作とメニュー

- タイトルバーに「ファイル」「再生」「表示」「その他」を配置
- 再生メニューから、秒数またはパーセンテージで指定箇所へ移動
- 表示メニューから波形の表示、再生ヘッドモード、表示範囲指定を操作
- Windows タスクバーの再生・先頭・次へボタンに対応（「次へ」は現状停止動作）
- ホットキーを設定画面から変更可能
- 通常キーと修飾キー付きマウスホイールを登録可能

### 3.3 設定

設定画面は次のカテゴリで構成する。

- 一般: 言語、テーマ、起動時に復元する項目
- ホットキー: キー・修飾キー・マウスホイール割り当て
- 数値: スキップ、音量、速度、履歴数、既定ズーム、曲切替待機時間
- 表示: 波形、ミニマップ、カーソルモード、詳細度、ズーム設定

表示カテゴリには「波形」「ミニマップ」の折りたたみ可能な詳細カテゴリがある。詳細カテゴリ単位の初期化ボタンと、未適用項目を示す `*` を提供する。

設定は `%LOCALAPPDATA%\PotatoMusicPlayer\` 配下へ保存する。

### 3.4 入力とダイアログ

- 波形表示範囲は秒数または `%` で入力する（例: `5`, `5%`）。
- 指定箇所は `秒`、`mm:ss`、`hh:mm:ss.ss`、`%` を受け付ける。
- 入力ダイアログは Esc でキャンセルする。
- Enter は入力が正しい場合だけ確定する。

### 3.5 波形とミニマップ

- 波形は曲全体から生成したピーク値のうち、現在の表示範囲を描く。生成中は進捗を表示し、設定が有効なら完成した部分から逐次表示する。結果はディスクへキャッシュできる。
- 表示幅は最小表示幅から曲全体の長さまでとする。波形上の `Ctrl + ホイール` で拡大・縮小し、通常ホイールまたは `Shift + ホイール` で範囲を移動する。表示メニューから秒数または割合でも幅を指定できる。
- 中央固定モードでは、再生位置が表示範囲の中央より左にある間は範囲を保ち、中央へ追いつくと追従する。右側にある場合は直ちに中央へ合わせる。中央の目印と実際の再生位置は別の線で示す。曲端では範囲の一部を曲外の空白として表示できる。
- 左流しモードでは波形を固定し、再生位置が右端に達したら次の表示ページへ移る。
- ミニマップは曲全体の波形、再生位置、表示範囲の緑枠を示す。枠の内部をドラッグすると範囲を移動する。中央固定では曲端が範囲の中央に来るまで曲外へ移動でき、左流しでは曲内に制限する。枠の外を押すとその位置へ枠が移り、ドラッグ中はマウスを追い、離した位置で一度だけ再生位置を確定する。
- 曲外を含む表示範囲では、緑枠は曲内に見えている区間だけを囲む。曲外へ続く側は薄いハンドルと外向きの矢印で示す。ハンドル操作は表示幅の変更に使い、中央固定では再生位置の相対割合を保つ両側ズームになる。
- 再生中の範囲移動や枠外からの位置指定は、操作中に再生を維持し、解放時に必要なら一度だけシークする。操作中の仮位置を波形とミニマップの再生位置表示に優先する。
- 左流しモードの片側ハンドルはつまんだ側だけを動かす。停止・一時停止中にドラッグしても、その操作だけでは再生を開始しない。

| 波形設定 | 既定値 |
| --- | ---: |
| 再生位置表示 | 中央固定 |
| 既定の表示幅 | 曲全体の100% |
| 最小表示幅／ズーム倍率／ホイール移動量 | 1秒／2倍／0.2秒 |
| 横・縦方向詳細度 | 各100 |
| ミニマップ高さ | 16px |
| 波形の逐次表示／ディスクキャッシュ | オン／オン |
| キャッシュ上限 | 512MB |

## 4. 設計構成

| 層 | 主な責務 | 主なファイル |

| ViewModel | 再生状態、設定反映、波形追従 | `ViewModels/MainViewModel.cs` |
| 再生サービス | LibVLC のライフサイクル、再生状態 | `Services/MediaService.cs` |

| 設定サービス | JSON の読み書きと既定値 | `Services/SettingsService.cs` |
| モデル | 再生状態、設定、ズーム状態 | `Models/` |
| 設定画面 | 設定編集と未適用表示 | `Views/SettingsWindow.xaml(.cs)` |
| テーマ | テーマ辞書の選択、OSテーマ変更への追従 | `Services/ThemeService.cs`、`Resources/Themes/` |

### 4.1 テーマと配色リソース

- Light／Dark はそれぞれ専用の配色辞書を使い、共通コントロールスタイルは `ThemeStyles.xaml` に置く。
- UI の色は `Surface...`、`Text...`、`Border...`、アクセントなど用途を示すテーマリソースから取得する。波形・ミニマップのCanvas描画色もテーマリソースを使う。
- System は Windows のアプリテーマ設定を参照し、起動中に設定が変わった場合も配色を切り替える。
- ビルド時に Light／Dark のリソースキー一致、XAML/C#からのリソース参照、主要なコントラスト比、UI色の直書きを検査する。テーマ外の固定色を加える場合は検査規約の対象となる。

## 5. 非機能方針

- 波形生成は UI スレッドを塞がない。
- 再生位置の表示は再生イベントの通知間隔に依存せず、画面描画フレームで補間する。
- 古い波形生成要求の結果は、後から開始された要求へ適用しない。
- 設定値は範囲検証し、不正値を保存しない。

## 6. 既知の制限

- プレイリスト、実際の次曲・前曲切替、フォルダスキャンは未実装。
- イコライザー、音量正規化、ループ区間指定は未実装。
- アプリ起動時、設定画面、Windows 標準ファイル選択ダイアログで一瞬白く表示される場合がある。WPF／Windows の初期描画に起因する既知問題として扱う。
- 自動テストプロジェクトは未作成で、再生・ドラッグ操作の確認は手動テストが中心。
