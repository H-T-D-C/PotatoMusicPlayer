# Potato Music Player - 仕様書

## アプリケーション概要
**アプリ名:** Potato Music Player  
**対応OS:** Windows 64bit  
**技術スタック:** C# + WPF  
**ウィンドウサイズ初期値:** 900px × 400px  
**UIテーマ:** ダーク／ライト／システム（VLC風の配色）
**オーディオエンジン:** LibVLCSharp

---

## 対応ファイル形式
- MP3
- FLAC
- WAV
- OGG

---

## 基本機能

### 1. ファイル再生
- ファイル選択して再生
- ファイルの頭出し可能（再生バーをクリック）
- メタデータ表示（曲名、アーティスト、時間、ビットレート等）

### 2. 再生制御
- 再生/一時停止
- 再生速度調整（デフォルト: 100%）
- ループ機能（ループなし → ループ1曲 → ループ全体 → ループなし）

### 3. UI表示要素
- **再生バー** - 現在位置を表示、クリックで頭出し可能
- **波形表示** - ファイル読み込み時に波形を表示
  - 表示形式: 動画編集ソフト風（音量レベルの棒グラフ）
  - 無音部分を視認しやすく
  - 表示形式: モノラル表示（1本の棒グラフ）
  - 色: グレイブルー（ダークテーマ基調）
- **メタデータ表示** - 曲名、アーティスト、ビットレート、サンプリングレート
- **時間表示** - 現在時刻 / 総時間
- **ループ状態表示** - 「Loop: OFF/1曲/ALL」
- **再生速度表示** - 現在の再生速度（例: 1.0x, 0.95x）

### 4. メニューバー (タイトルバーに配置)

#### ファイル
- ファイルを開く（ダイアログでファイル選択）
- ファイルのフォルダを開く (再生中のメディアがある場合のみ、そのメディアがあるフォルダを開く)
- ファイルのフォルダをターミナルで開く (再生中のメディアがある場合のみ、そのメディアがあるフォルダを開く)
- 最近使ったファイル（最大50個まで保持）
- 終了

#### 編集
- 設定を開く

### 再生
- 一時停止/再生
- 停止 (メディアの先頭に戻り、一時停止)
- 前へ(ファイル最初へ戻る)/次へ
- 速度調整 > 100%にセット/5%遅く/5%速く/指定速度にセット
- 5秒スキップ/戻る
- 指定時間へ移動

#### 表示
- ウィンドウサイズ固定 on/off
- 常に最前面 on/off
- 波形の表示/非表示
- 全画面表示

#### その他
- バージョン情報・概要

## ホットキー機能

### デフォルトキーバインド

| 機能 | キー | 備考 |
|------|------|------|
| 再生/停止 | Space | - |
| 5秒戻る | ← (左矢印) | - |
| 5秒進む | → (右矢印) | - |
| 音量 5% 上げる | ↑ (上矢印) | - |
| 音量 5% 下げる | ↓ (下矢印) | - |
| ミュート/ミュート解除 | m| - |
| 0.1秒戻る | , (コンマ) | - |
| 0.1秒進む | . (ドット) | - |
| ファイルの最初に戻る | Home | - |
| 再生停止 | End | 次に同じファイル再生時は頭から |
| 再生速度 5% 低下 | A | - |
| 再生速度 5% 上昇 | D | - |
| 再生速度を 100% にリセット | S | - |

### ホットキー設定
- **設定変更可能:** ユーザーが後からホットキーをカスタマイズ可能
- **衝突チェック:** 同じキーが複数の機能に割り当てられるのを防止
- **設定画面:** 「編集」メニュー → 「設定」 → 「ホットキー」項目から変更
- **永続化:** 設定ファイルに保存し、次起動時にも同じキーバインドを使用

## タスクバー統合

### Windows タスクバー連携
- **再生/停止ボタン**
- **前へボタン(◀◀)** - ファイルの最初に戻る（Homeキーと同じ）
- **次へボタン(▶▶)** - 次の曲再生（実際は再生停止。プレイリスト機能がないため）

---

## ウィンドウ機能

### ウィンドウ仕様
- **初期サイズ:** 900px(幅) × 400px(高さ)
- **リサイズ可能:** ユーザーが自由にサイズ変更可能
- **最小化:** タスクバーアイコンをクリックで復帰
- **再生中の動作:** 最小化状態でも再生継続
- **最前面固定:** 表示メニューで on/off 可能
- **ウィンドウサイズ固定:** 表示メニューで on/off 可能

---

## 設定・ファイル保存

### 設定を可能にする項目
- ホットキー
- ホットキーを設定可能な数値項目(5秒進む, 音量を5%上げる. etc.)の、数値
- 最近再生したメディアを保存するかどうか
- 最近再生したファイルの保存個数(デフォルト50個)
- 波形の表示/非表示
- 音量を毎起動時に指定した値にリセットするかどうか
- 再生速度を毎起動時に指定した値にリセットするかどうか
- 言語 英語(English US)/日本語(Japanese)
- テーマ（ライト / ダーク / システム）
- 出力デバイス デフォルト/任意指定
- 音量の上限(デフォルト200%)

### 設定ファイル保存位置
- `%APPDATA%\Local\PotatoMusicPlayer\` 配下に保存

### 保存内容(設定を可能にする項目も保存する)
- ホットキー設定
- 最近使ったファイル（設定した数）
- ウィンドウサイズ、最前面設定、サイズ固定設定
- 再生速度（次起動時に保持する場合）

## 技術仕様

### 開発環境
- **言語:** C#
- **UI フレームワーク:** WPF (Windows Presentation Foundation)
- **オーディオエンジン:** LibVLCSharp
- **メタデータ取得:** TagLibSharp
- **設定保存:** JSON または XML

### 外部ライブラリ
- **LibVLCSharp** - VLCエンジン利用
- **TagLibSharp** - メタデータ読み込み
- **Newtonsoft.Json** - JSON設定・言語ファイル管理
- **NAudio** - 波形解析など一部の音声処理

## 現在の対応状況（2026年9月）

### 対応済み
- MP3 / FLAC / WAV / OGG の選択、LibVLCSharpによる再生・一時停止・停止
- TagLibSharpによる曲名、アーティスト、ビットレート、サンプルレート、時間の表示
- シークバーと波形のクリック／ドラッグシーク、上下対称の波形、再生カーソル
- ループ（OFF / 1曲 / ALL）、再生速度変更、音量最大200%、ミュート（アイコン・`M`キー）
- カスタムタイトルバー、メニュー、最小化・終了、リサイズ、最前面、サイズ固定、全画面
- Windowsタスクバーの前へ・再生／一時停止・停止ボタン（再生状態に応じて表示更新）
- 最近使ったファイル、ウィンドウ状態、音量・速度などのJSON保存
- 設定画面（一般、ホットキー、数値、音量、表示）と、ホットキーの変更・リセット・クリア・組み合わせキー
- `Resources/Languages/ja-JP.json` / `en-US.json` による日本語・英語切り替え
- ダーク／ライト／システムテーマ、テーマに応じた設定画面・メニュー・波形・スピーカーアイコン

### 部分対応・既知の制限
- 翻訳キーは主要メニューと設定画面が中心で、一部のダイアログやステータス文言は未翻訳
- OGG / FLAC の波形解析はWindowsのデコーダー環境に依存する
- 出力デバイスや起動時リセット項目は設定モデルに存在するが、UI連携は未完了
- プレイリストがないため、タスクバーの「次へ」は現在の曲を停止する動作

### 未対応
- プレイリスト、フォルダスキャン、自動再生キュー
- イコライザー、音量正規化、ループ区間指定
- フォント変更、ポータブル版・インストーラー

## 開発ロードマップ

### Phase 1: 安定化
1. 波形解析のキャンセル、キャッシュ、失敗時の明示を追加する。
2. 再生・音量・設定保存を対象に自動テストを追加する。
3. 設定JSONのバージョン管理と不正値の復旧を整備する。

### Phase 2: 設定と多言語の完成
1. 残りのメニュー、ダイアログ、ステータスを言語JSONへ移行する。
2. 出力デバイス選択と起動時リセット設定を実際の再生処理へ接続する。
3. 言語ファイル追加時の検証手順を整備する。

### Phase 3: 再生体験の拡張
1. プレイリスト、フォルダスキャン、次曲／前曲を実装する。
2. タスクバー操作をプレイリストへ対応させる。
3. イコライザー、音量正規化、ループ区間指定を追加する。

### Phase 4: 品質・配布
1. CPU・メモリ使用量と大規模ファイルの解析時間を最適化する。
2. アクセシビリティ、キーボード操作、DPIスケーリングを確認する。
3. ポータブル版とインストーラーを作成し、依存DLLと対応OSを検証する。
