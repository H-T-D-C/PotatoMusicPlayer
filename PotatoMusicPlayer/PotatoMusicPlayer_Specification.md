# Potato Music Player - 仕様書

## 現在の設計・実装状況（2026-09-23）

この節は、本文中の初期計画や「予定」と書かれた項目を読む際の基準です。実装済みの詳細仕様は [WaveformZoom_Specification.md](WaveformZoom_Specification.md) に分離しています。

### 実装済みの主要構成

- `MainWindow.xaml(.cs)` がタイトルバー、再生操作、波形、シークバー、ミニマップを担当する。
- `MainViewModel` が再生状態、シーク、ループ、波形追従を管理する。
- `MediaService` が LibVLCSharp を介して再生を制御する。
- `WaveformService` が波形を非同期生成し、`WaveformZoomService` が表示範囲の制約・ズーム・スクロールを計算する。
- `AppSettings` と `SettingsService` が JSON 設定を保存する。設定画面は一般・ホットキー・数値・表示カテゴリを持つ。

### 実装済み機能の補足

- ホットキーは設定画面から変更でき、通常キーだけでなく修飾キー付きマウスホイールにも対応する。
- 波形は表示／非表示、中央固定／左流、横方向・縦方向詳細度、ミニマップ高さを設定できる。
- 波形の表示範囲は秒数またはパーセンテージで指定でき、指定箇所への移動も同じ入力形式に対応する。
- 曲末からのループ再生には、設定した曲切替待機時間を適用する。プレイリスト未実装のため、Loop: 全体も現在の曲を先頭から再生する。

### 現在の制限・既知の問題

- プレイリスト、実際の次曲／前曲切替、イコライザー、音量正規化は未実装。
- アプリ起動時、設定ウィンドウ、Windows 標準ファイル選択ダイアログで一瞬白く表示されることがある。WPF／Windows の初期描画に起因するため、現時点では修正対象外。
- UI の再生・ドラッグ操作は手動確認が中心で、自動テストプロジェクトは未作成。

## 基本機能

### 1. ファイル再生
- ファイル選択して再生
- ファイルの頭出し可能（再生バーをクリック）
- メタデータ表示（曲名、アーティスト、時間、ビットレート等）

### 2. 再生制御
- 再生/一時停止
- 再生速度調整（デフォルト: 100%）
- ループ機能（ループなし → ループ1曲 → ループ全体 → ループなし）

### 3. UI表示要素
- **再生バー** - 現在位置を表示、クリックで頭出し可能
- **波形表示** - ファイル読み込み時に波形を表示
  - 表示形式: 動画編集ソフト風（音量レベルの棒グラフ）
  - 無音部分を視認しやすく
  - 表示形式: モノラル表示（1本の棒グラフ）
  - 色: グレイブルー（ダークテーマ基調）
- **メタデータ表示** - 曲名、アーティスト、ビットレート、サンプリングレート
- **時間表示** - 現在時刻 / 総時間
- **ループ状態表示** - 「Loop: OFF/1曲/ALL」
- **再生速度表示** - 現在の再生速度（例: 1.0x, 0.95x）

### 4. メニューバー (タイトルバーに配置)

#### ファイル
- ファイルを開く（ダイアログでファイル選択）
- ファイルのフォルダを開く (再生中のメディアがある場合のみ、そのメディアがあるフォルダを開く)
- ファイルのフォルダをターミナルで開く (再生中のメディアがある場合のみ、そのメディアがあるフォルダを開く)
- 最近使ったファイル（最大10個まで保持）
- 終了

#### 編集
- 設定を開く

### 再生
- 一時停止/再生
- 停止 (メディアの先頭に戻り、一時停止)
- 前へ(ファイル最初へ戻る)/次へ
- 速度調整 > 100%にセット/5%遅く/5%速く/指定速度にセット
- 5秒スキップ/戻る
- 指定時間へ移動

#### 表示
- ウィンドウサイズ固定 on/off
- 常に最前面 on/off
- 波形の表示/非表示
- 全画面表示

#### その他
- バージョン情報・概要

## ホットキー機能

### デフォルトキーバインド

| 機能 | キー | 備考 |
|------|------|------|
| 再生/停止 | Space | - |
| 5秒戻る | ← (左矢印) | - |
| 5秒進む | → (右矢印) | - |
| 音量 5% 上げる | ↑ (上矢印) | - |
| 音量 5% 下げる | ↓ (下矢印) | - |
| ミュート/ミュート解除 | m| - |
| 0.1秒戻る | , (コンマ) | - |
| 0.1秒進む | . (ドット) | - |
| ファイルの最初に戻る | Home | - |
| 再生停止 | End | 次に同じファイル再生時は頭から |
| 再生速度 5% 低下 | A | - |
| 再生速度 5% 上昇 | D | - |
| 再生速度を 100% にリセット | S | - |

### ホットキー設定
- **設定変更可能:** ユーザーが後からホットキーをカスタマイズ可能
- **衝突チェック:** 同じキーが複数の機能に割り当てられるのを防止
- **設定画面:** 「編集」メニュー → 「設定」 → 「ホットキー」項目から変更
- **永続化:** 設定ファイルに保存し、次起動時にも同じキーバインドを使用

## タスクバー統合

### Windows タスクバー連携
- **再生/停止ボタン**
- **前へボタン(◀◀)** - ファイルの最初に戻る（Homeキーと同じ）
- **次へボタン(▶▶)** - 次の曲再生（実際は再生停止。プレイリスト機能がないため）

## 設定・ファイル保存

### 設定を可能にする項目
- ホットキー
- ホットキーを設定可能な数値項目(5秒進む, 音量を5%上げる. etc.)の、数値
- 最近再生したメディアを保存するかどうか
- 最近再生したファイルの保存個数(デフォルト50個)
- 波形の表示/非表示
- 音量を毎起動時に指定した値にリセットするかどうか
- 再生速度を毎起動時に指定した値にリセットするかどうか
- 言語 英語(English US)/日本語(Japanese)
- 出力デバイス デフォルト/任意指定
- 音量の上限(デフォルト200%)

### 設定ファイル保存位置
- `%APPDATA%\Local\PotatoMusicPlayer\` 配下に保存

### 保存内容(設定を可能にする項目も保存する)
- ホットキー設定
- 最近使ったファイル（設定した数）
- ウィンドウサイズ、最前面設定、サイズ固定設定
- 再生速度（次起動時に保持する場合）

## 現在の対応状況

### 対応済み
- MP3 / FLAC / WAV / OGG のファイル選択、LibVLCSharpによる再生・停止・一時停止
- 曲名、アーティスト、ビットレート、サンプリングレート、再生時間の表示
- 再生位置のシーク、5秒移動、速度変更、ループ（1曲 / 全体）
- 音量スライダー（最大200%）、ミュート、`M`キー、スピーカー画像の音量段階表示
- カスタムタイトルバー、最小化・終了、リサイズ、常に最前面、サイズ固定
- ダークテーマ、波形の非同期生成・描画、再生カーソル、波形クリック／ドラッグシーク
- 最近使ったファイル、ウィンドウ設定、音量上限、波形表示設定のJSON保存
- 設定画面の一般・音量・表示カテゴリ、Japanese (日本) / English (US) の選択
- `Resources/Languages/*.json` による表示文言の切り替え基盤

### 部分対応・既知の制限
- 言語切り替えは主要メニューと設定画面を対象とし、全てのサブメニュー・ステータス文言は未翻訳
- OGG / FLAC の波形生成は Windows Media Foundation の環境に依存する
- ホットキーはコードに定義された固定割り当てで、設定画面からの変更には未対応
- 音量・再生速度の「起動時リセット」や出力デバイス選択は設定項目のみで、動作連携は未完了

### 未対応
- プレイリスト、フォルダスキャン、自動再生キュー
- Windowsタスクバーの再生操作ボタン
- イコライザー、音量正規化、ループ区間指定
- ライトテーマ、フォント変更、ポータブル配布

## 開発ロードマップ

### Phase 1: 安定化（次）
1. 波形解析のキャンセル、キャッシュ、失敗時表示を追加する。
2. OGG / FLAC のデコーダー差異を検証し、対応形式を明示する。
3. 再生・音量・設定保存の自動テストを追加する。

### Phase 2: 設定と多言語
1. JSON言語キーを全メニュー、ダイアログ、ステータスへ拡張する。
2. ホットキー、起動時リセット、出力デバイスを設定画面から変更可能にする。
3. 設定値の後方互換性と不正値の復旧処理を整備する。

### Phase 3: 再生体験の拡張
1. プレイリスト、フォルダスキャン、次曲／前曲を実装する。
2. タスクバー統合と、波形・シークバーの拡大表示を追加する。
3. イコライザー、音量正規化、ループ区間指定を追加する。

### Phase 4: 品質・配布
1. ライトテーマ、フォント設定、アクセシビリティを整備する。
2. CPU・メモリ使用量を計測して最適化する。
3. ポータブル版とインストーラーを作成し、対応OS・依存DLLを検証する。
